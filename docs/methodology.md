# Методика экспериментальной проверки гипотез

Проект проверяет гипотезы H1-H5 о применимости Web Components, React, Vue, Angular и Vanilla JavaScript на одинаковых UI-сценариях: Counter, Todo List, Product Card, Tabs и Form Component.

Проверка выполняется по критериям K1-K10 и профилям P-A...P-D. Оценки используются как учебно-исследовательская модель, а не как абсолютный рейтинг технологий.

## Гипотезы

- H1 — Web Components сильнее по инкапсуляции DOM и изоляции стилей.
- H2 — Web Components лучше подходят для переносимых виджетов и дизайн-систем.
- H3 — React и Vue удобнее для интерактивных компонентов с активным состоянием.
- H4 — Angular рационален для крупных корпоративных SPA.
- H5 — Vanilla JS минимален по зависимостям, но хуже масштабируется.

## Группы метрик

- Измеряемые: файлы, строки кода, зависимости, размер сборки, время сборки, условное время рендера, время реакции интерфейса.
- Экспертные: читаемость, сложность реализации, поддерживаемость, повторное использование, применимость в реальных проектах.

## Ограничения

Результаты зависят от версии инструментов, опыта разработчика, качества реализации, требований продукта и выбранного способа сборки. Angular вынесен в отдельное приложение монорепозитория, потому что его сборочная модель отличается от Vite-приложения.
